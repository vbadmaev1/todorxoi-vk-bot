# todorxoi-vk — бот «тодо бичиг» ВКонтакте

Версия [телеграм-бота todorxoi](https://github.com/vbadmaev1/todorxoi-bot)
для сообществ ВКонтакте. Переводит калмыцкий текст между тремя формами
записи и рисует настоящее вертикальное письмо картинкой.

```
калмыцкая кириллица ──► транслитерация ──► тодо бичиг ──► картинка
       хальмг              xalimaq          ᡍᠠᠯᡅᡏᠠᡎ          🖼

фото или скан с тодо бичиг ──► кириллица + транслитерация + тодо бичиг (юникод)
```

Умеет то же, что телеграм-версия: режимы транслитерации, тодо бичиг,
картинки и исправления текста без ә ө ү һ җ ң, распознавание фото,
настройки картинки и знаков препинания, 👍/👎 с приёмом исправлений,
`/stats` и `/export` для админов. Что это всё такое и как устроено
внутри — в [README телеграм-версии](https://github.com/vbadmaev1/todorxoi-bot#readme).
Здесь — только про ВКонтакте.

## Как устроено

```
bot/vk/       клиент VK API: вызовы методов, Long Poll, загрузка фото и
              документов, клавиатуры — от логики бота не зависит
bot/          логика бота: диспетчер, обработчики, тексты, кнопки, база
core/ model/ assets/   ядро — копия из todorxoi-bot (см. ниже)
tests/        прогон на поддельном VK, без сети и ключа
```

**Ядро общее с телеграм-ботом.** `core/`, `model/` и `assets/` — копия из
todorxoi-bot, с какого коммита — в `CORE_VERSION`. Ядро от мессенджера не
зависит, поэтому меняется только там, а сюда переносится одной командой:

```bash
tools/sync_core.sh ../todorxoi-bot          # или ../todorxoi-bot main
python -m tests.smoke
```

Копия, а не git submodule, — чтобы деплой был обычным `git clone` и
сервер не зависел от второго репозитория.

**Свой клиент VK вместо фреймворка.** Боту нужно десяток методов API;
обёртка на aiohttp (`bot/vk/`) — пара сотен строк, без лишних
зависимостей и без сюрпризов от чужих мажорных версий. Ограничение
частоты (20 запросов в секунду на ключ сообщества) и повторы при
ошибках сети и «слишком много запросов» — там же.

### Чем ВКонтакте отличается от Telegram

| | Telegram-версия | VK-версия |
|---|---|---|
| Приём сообщений | long polling Bot API | Bots Long Poll API — тоже без домена и сертификата |
| Меню команд | кнопка «/» | нет; нижнее меню с кнопками режимов, «Настройки», «Фото → текст», «Помощь». Текущий режим на клавиатуре синий. Команды `/todo текст` тоже работают |
| Первое сообщение | `/start` | кнопка «Начать» (payload `{"command":"start"}`), слово «Начать» |
| Разметка | HTML: жирный, моноширинный | нет — плоский текст, структура держится на эмодзи и пустых строках |
| Кнопки под ответом | callback | callback, если клиент умеет (VK сообщает это в `client_info`); иначе те же кнопки текстовые — нажатие приходит сообщением с payload |
| Ответ на нажатие | всплывающее уведомление | плашка (snackbar) до 90 символов; длиннее — сообщением |
| После 👍/👎 | кнопки меняются на «оценено» | кнопки остаются: `messages.edit` переписывает сообщение целиком, вместе с вложениями. Повторное нажатие просто обновляет оценку |
| Экран настроек | 8 рядов кнопок | inline-клавиатура VK — до 6 рядов, поэтому настройки картинки по две в ряд, а палитра фона листается (11 цветов + «Назад» не влезают) |
| Длинный текст картинкой | по листу на сообщение | до 10 листов в одном сообщении |
| Прозрачный фон | документом | документом — фото VK пережимает в JPEG |
| Подпись к картинке | до 1024 символов | обычный текст сообщения, до 4096 — ответ на фото почти всегда одним сообщением |
| Режим | в памяти, до перезапуска | в базе (`user_settings.mode`), переживает перезапуск |
| Беседы | — | бот отвечает на команды и на упоминание `[club…\|@бот] текст`, обычные реплики не трогает |
| PDF | подсказка «пришлите картинкой» | то же |

## Запуск

### 1. Сообщество

Боту нужно сообщество ВКонтакте (можно новое, закрытое — для проверки).

1. **Управление → Работа с API → Ключи доступа → Создать ключ.** Права:
   **управление сообществом** (обязательно: без него VK не даёт Long Poll —
   `groups.getLongPollServer: [15] Access denied … current scopes`, и бот
   не получает сообщений), сообщения сообщества, фотографии, документы.
   Права готового ключа не меняются — забыли отметить, создайте новый.
   С правом управления бот сам включит всё из пунктов 2–3
   (`VK_SETUP_LONGPOLL=true`).
2. **Работа с API → Long Poll API:** «Включён», версия API **5.199**.
   На вкладке «Типы событий» — «Входящее сообщение» и «Действие с
   сообщением» (это нажатия callback-кнопок).
3. **Сообщения:** «Включены». **Настройки для бота:** «Возможности ботов» —
   включены, «Кнопка „Начать“» — по желанию, «Разрешать добавлять
   сообщество в беседы» — если нужен бот в беседах.

### 2. Бот

```bash
git clone https://github.com/vbadmaev1/todorxoi-vk-bot.git
cd todorxoi-vk-bot

python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env     # впишите VK_TOKEN и свой id в ADMIN_IDS
python -m bot.main
```

В логе должно появиться `сообщество: … бот запущен, жду сообщений`.
Напишите сообществу — бот ответит.

Проверить, что всё на месте, без ключа и без сети:

```bash
python -m tests.smoke
```

Тест поднимает поддельный VK на localhost (`tests/fake_vk.py`) и гоняет
через настоящий HTTP-клиент сценарии целиком: меню, режимы, картинки,
фото, оценки и исправления, настройки, старые клиенты без callback-кнопок,
беседы, админку, Long Poll с протухшим ключом. Поддельный VK отклоняет
то же, что настоящий: слишком большие клавиатуры, длинные подписи кнопок,
больше 10 вложений, сообщения без `random_id`.

### Деплой

Как у телеграм-версии: `docker compose up -d --build` или systemd-юнит из
`deploy/todorxoi-vk.service`. Экземпляр должен быть ровно один: два
процесса с одним ключом получат одни и те же события и ответят дважды.
Телеграм- и VK-бот друг другу не мешают — их можно держать на одном сервере,
каждый в своей папке.

Память такая же, как у телеграм-версии: ~300 МБ в покое, пик ~460 МБ на
распознавании полной страницы. Тариф с 1 ГБ — с запасом.

**Папку `data/` нужно вынести в volume** — в ней база с исправлениями.
В `docker-compose.yml` это уже сделано.

### Переменные окружения

Все — в `.env.example` с комментариями. Обязательная одна: `VK_TOKEN`.
Стоит сразу заполнить `ADMIN_IDS` (id ВКонтакте, числом), иначе `/stats` и
`/export` не будут работать ни у кого.

## Данные

Схема базы та же, что у телеграм-версии, — выгрузки `/export` одинаковые,
восстановление из лога тоже:

```bash
python -m tools.restore_from_jsonl events.jsonl --db data/todorxoi.sqlite3
```

`user_id` и `chat_id` здесь — id ВКонтакте (`chat_id` — peer_id диалога),
`username` пустой. Для фото в `input_text` записаны id вложения и ссылка на
картинку на серверах VK.
